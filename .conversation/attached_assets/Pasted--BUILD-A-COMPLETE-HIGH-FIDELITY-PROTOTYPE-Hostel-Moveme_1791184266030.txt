# BUILD A COMPLETE HIGH-FIDELITY PROTOTYPE

## Hostel Movement, Leave, QR & Biometric Security Platform

Design and generate a **complete, production-quality interactive UI prototype** for a modern college **Hostel Movement & Security Management Platform**.

This is NOT a traditional college ERP.

It is a modern, mobile-first, real-time hostel movement platform that combines:

* Student movement requests
* Short outings
* Local permissions
* Outstation/home-town leave
* Emergency movement
* Approval workflows
* Dynamic QR verification
* Security gate verification
* Biometric fingerprint verification
* Parent notifications
* Mentor notifications
* HOD notifications
* Warden notifications
* Security verification
* Live movement tracking
* Overdue return alerts
* Reports
* Audit logs
* Hostel and gate management

The prototype must look like a **premium modern SaaS/security product**, not an old college management system.

---

# 1. DESIGN DIRECTION

Create a polished, modern interface inspired by:

* Apple-quality simplicity
* Modern SaaS dashboards
* Security operations dashboards
* Modern fintech-level information hierarchy
* Clean mobile applications
* Real-time monitoring systems

Visual characteristics:

* Minimal
* Professional
* Clean
* Premium
* Spacious
* Highly readable
* Strong hierarchy
* Subtle animations
* Rounded cards
* Soft shadows
* Clear status indicators
* Modern typography
* Excellent responsive behavior

Avoid:

* Old ERP appearance
* Excessive tables everywhere
* Tiny text
* Overloaded dashboards
* Too many colors
* Cheap gradients
* Generic Bootstrap-looking UI
* Excessive glassmorphism
* Cartoon-like icons
* Fake AI gimmicks
